# Contracts

Contract-first foundation for HCCv2.

- `openapi/core-api.yaml`: Core REST API surface
- `schemas/agent-envelope.schema.json`: Envelope required for all agent messages
- `schemas/node-state.schema.json`: Canonical node state payload
- `schemas/service-definition.schema.json`: Service model + action definitions
- `schemas/widget-definition.schema.json`: Widget registry entry model
- `examples/`: Valid starter examples for integration and tests
